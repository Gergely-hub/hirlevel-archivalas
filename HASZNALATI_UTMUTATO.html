Hírlevelek helyi archiválása IMAP levelező fiókokból

Gyors kezdés

  1. Levelező fiók — Levelezés → Levelező fiókok…
  2. Hírlevél (forrás) — bal oldalon + Új hírlevél, feladó e-mail cím megadása
  3. Ellenőrzés — Most ellenőriz, vagy a forrás melletti frissítés (🔄)

1. Levelező fiók hozzáadása

Levelezés → Levelező fiókok… Több fiók is lehet (pl. Gmail + Outlook). A szinkron mindegyiken végigmegy.

Szolgáltató választása

SzolgáltatóBejelentkezésIMAP (háttérben)
Gmail Alkalmazásjelszó (2FA után) imap.gmail.com:993
Outlook / Hotmail / Live Bejelentkezés Microsoft-fiókkal — megnyílik a böngésző, ott jelentkezz be; utána a program menti a tokent outlook.office365.com:993
Yahoo Alkalmazásjelszó (Yahoo fiókbiztonság) imap.mail.yahoo.com:993
iCloud Alkalmazás-specifikus jelszó imap.mail.me.com:993
Freemail / Citromail / Vipmail Webes levelezés jelszava imap.*.hu:993
Egyéni / más szolgáltató Jelszó (szolgáltató szerint) Levelező szerver + port megadása

Outlook lépései

  1. Szolgáltató: Outlook / Hotmail / Live
  2. Add meg az e-mail címet és a megjelenített nevet
  3. Kattints: Bejelentkezés Microsoft-fiókkal
  4. A böngészőben jelentkezz be (email, jelszó, 2FA) — nincs külön eszközkód másolás
  5. Siker után a program automatikusan menti a fiókot
  6. Opcionális: Kapcsolat tesztelése a fiók űrlapon
A Microsoft bejelentkezés általában minden programindítás után megmarad (refresh token). Új bejelentkezés csak akkor kell, ha a token érvénytelenné válik.

Gmail lépései

  1. Google fiók → Biztonság → Alkalmazásjelszavak
  2. Szolgáltató: Gmail, jelszó mezőbe az alkalmazásjelszó
  3. Mentés, majd kapcsolatteszt vagy szinkron
A jelszavak és Outlook tokenek a gépeden, a %LOCALAPPDATA%\HirlevelKoveto\config.json fájlban tárolódnak (nem titkosítva). Ahol lehet, alkalmazásjelszót használj a fő jelszó helyett — korlátozott, visszavonható; a fájl ettől még érzékeny marad. Erős Windows-jelszó és BitLocker ajánlott. Részletek: Jogi Dokumentumok Központ → Biztonság és adatvédelem.

2. Hírlevél források és szinkron

Egy forrás = egy feladó (pl. hirlevel@ceg.hu). A program az IMAP postafiókodból kikeresi az adott feladótól érkező leveleket.

  • Most ellenőriz — új levelek behúzása minden fiókon / forráson
  • 🔄 a forrás során — csak az adott forrás frissítése
  • Régebbi levelek betöltése — múltbeli hírlevelek is (lassú, első alkalommal érdemes)

Időzített levélellenőrzés: Beállítások → Frissítési intervallum (perc). Ez nem biztonsági mentés.

3. Levelek olvasása és keresés

  • Bal oldalon: hírlevél / címke választása
  • Középen: levéllista; jobbra: olvasó nézet
  • Szűrők: olvasatlan, kedvenc, dátum; kereső felül
  • Export: Word / PDF (egy levél vagy lista)

4. Törlés és adatok

  • Levél törlése — csak a helyi archívumból; a levelező szerveren megmarad
  • Forrás + levelek törlése — bal oldalon válaszd ki a forrást, majd Törlés…
  • Csak helyi levelek — Helyi levelek törlése…
  • Egy levél — törlés a buborékon
  • Fiók törlése — Levelezés → Levelező fiókok… → Törlés

Részletes adatkezelés, mentés, jogi tájékoztatók: Súgó → Jogi Dokumentumok Központ.

5. Mentés és biztonsági másolat

  • Fájl → Mentés… — zip az utolsó használt mappába (időbélyeges név)
  • Fájl → Mentés másként… — mappa és fájlnév választása
  • Fájl → Backup visszaállítás… — korábbi zip visszatöltése
  • A zip biztonsági másolatot csak te indíthatod; nincs automatikus háttérmentés (a levelek szinkronkor automatikusan a helyi adatbázisba kerülnek).
  • Adatok helye: %LOCALAPPDATA%\HirlevelKoveto\ (config, adatbázis)

6. Gyakori kérdések

Outlook: „Basic auth tiltva”

Használd a Bejelentkezés Microsoft-fiókkal gombot; sima jelszó nem működik.

„Nincs token” / bejelentkezés sikertelen

Outlook fióknál ismételd a Microsoft bejelentkezést, majd Mentés. Ha továbbra is hibás, jelezd a Súgó → Hibabejelentő… menüben.

ProtonMail (kísérleti)

Csak a Proton Mail Bridge programmal: Bridge fusson, profil: ProtonMail — kísérleti (Bridge) (127.0.0.1, port 1143, Bridge jelszó). Kísérleti funkció — nincs garancia.
